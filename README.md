# JOGO_2D
Jogo para treinar o versionamento de código.

25/08 - A gente começou a desenvolver no GitHub DeskTop, na Unity e no GitHub. Aprendemos a fazer o Repositório, Push, Commit, Branch, Merge e Pull.
Push -> Envia seus commits para o GitHub.
Commit -> Uma foto do projeto, com mensagem sua.
Pull  -> Traz o que os colegas enviaram.
Branch -> Linha paralela para testar sem quebrar o jogo.
Merge -> Junt o trabalho de duas pessoas.
Versionamento de código -> Um sistema que guarda o histórico do projeto: cada alteração vira um ponto de salvamento - como um save game do seu código.

O Game Design de um jogo, criado pelo profissional chamado "Game Designer", é a área que cuida da elaboração do projeto, compreendendo seus níveis, puzzles, artes, animações, mecânicas, roteiros e muito mais. Aprendemos o 1º tipo de Game Design de Mecânica: Cuida de todo o processo criativo de como o jogo será, seus elementos jogáveis, tais como objetos,atributos, ações, regras e etc.

08/10/2026 -> Scene Manager (gestor de cenas) é uma ferramenta ou componente de software usado em várias indústrias para organizar, carregar, mudar e renderizar diferentes partes ou estados de um projeto ou ambiente virtual. Dependendo da área de atuação (como computação gráfica, desenvolvimento de jogos ou áudio), o termo assume significados específicos:
1. Em 3ds Max (Pulze Scene Manager): No ecossistema de arquitetura e design 3D, o Pulze Scene Manager é um plugin popular para o 3ds Max.Permite gerir configurações de iluminação, câmaras, materiais e definições de renderização num único ficheiro. batch rendering) com um só clique.
2. Em Motores de Jogos (Unity, Godot, Phaser): Nos motores de jogos, o SceneManager é uma classe ou API de programação responsável por controlar o fluxo do jogo entre diferentes níveis ou menus. Permite carregar, descarregar ou mudar de cena (por exemplo, passar do menu principal para o nível 1). Suporta carregamento síncrono ou assíncrono, assim como carregamento aditivo (adicionar cenas em camadas, como carregar um cenário e uma interface em cima).
3. Em Áudio e Equipamento de Música (Ex: Fractal Audio): Em processadores de efeitos e modeladores de amplificadores para guitarra (como o Fractal FM3), o "Scene Manager" ou sistema de Scenes gere blocos de efeitos, canais e estados predefinidos dentro de um único preset, permitindo alternar sons instantaneamente sem latência.
