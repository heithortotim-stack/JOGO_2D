# JOGO_2D
Jogo para treinar o versionamento de código.

25/08 - A gente começou a desenvolver no GitHub DeskTop, na Unity e no GitHub. Aprendemos a fazer o Repositório, Push, Commit, Branch, Merge e Pull.
Push -> Envia seus commits para o GitHub.
Commit -> Uma foto do projeto, com mensagem sua.
Pull  -> Traz o que os colegas enviaram.
Branch -> Linha paralela para testar sem quebrar o jogo.
Merge -> Junt o trabalho de duas pessoas.
Versionamento de código -> Um sistema que guarda o histórico do projeto: cada alteração vira um ponto de salvamento - como um save game do seu código.

27/08 -> Hoje o Vinicius nos apresentou sobre o Game Design Document (GDD), é começou a nos apresentar sobre o Game Design. O Game Design de um jogo, criado pelo profissional chamado "Game Designer", é a área que cuida da elaboração do projeto, compreendendo seus níveis, puzzles, artes, animações, mecânicas, roteiros e muito mais. Aprendemos o 1º tipo de Game Design de Mecânica: Cuida de todo o processo criativo de como o jogo será, seus elementos jogáveis, tais como objetos,atributos, ações, regras e etc.
